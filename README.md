# اکانتینو — دموی تعاملی

نمونه فارسی و راست‌به‌چپ فروش اکانت و پیگیری سفارش.

## نمایش

[باز کردن دمو](https://rashiin.github.io/accountino-demo/)

فایل `index.html` مستقل است و با مرورگر اجرا می‌شود.

## امکانات نمایشی

- فروشگاه، دسته‌بندی و جست‌وجو
- ثبت سفارش نقدی یا اقساطی آزمایشی و کد تخفیف ACCOUNTINO10
- پیگیری سفارش و تغییر وضعیت از نمای مدیریت
- پیام‌های محلی، مشخصات دستگاه و رزرو نوبت
- کیف پول و محاسبه سهم کارشناس به صورت نمونه

تمام اطلاعات و قیمت‌ها نمونه‌اند. پرداخت، دیجی‌پی، پیامک، احراز هویت و پشتیبانی واقعی به این نسخه متصل نیستند. اطلاعات فقط در مرورگر ذخیره می‌شوند. این نمونه یک رابط واکنش‌گراست؛ PWA قابل نصب یا اپلیکیشن مستقل نیست.
